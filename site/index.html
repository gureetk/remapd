Android TV and Google TV · no root

Every button on your TV remote, working.

remapd makes every button on a Bluetooth remote work on Android TV and Google TV. A small program and an app. No root, no other app needed.

The problem

Some remote buttons do nothing.

A Bluetooth remote can send buttons that Android TV has no name for. Two things get in the way.

One name for many buttons

The kernel reports any HID usage it doesn't know as KEY_UNKNOWN. Remapping apps see all of those buttons as the same button, so they can't tell them apart.

A key layout for another remote

The Chromecast already has a key layout file for the ACE666BT's ID, 0508:0110. It was made for a different remote, and it turns the colour buttons and Play/Pause into UNKNOWN.

How it works

Two small parts.

remapd changes the kernel's keymap for each button, from the one user on your TV that's allowed to: the ADB shell user.

remapd

The program

One C file with no dependencies. It runs as the ADB shell user and keeps going until the TV restarts. It notices when a remote reconnects, applies your buttons again, and puts the original keymap back when it stops.

remapd app

The app

Sets everything up once, lets you pick what each button does, and starts remapd again after every restart. It has its own adb client, so no computer or other app is needed after setup.

What a button can do

Four actions, one per button.

map

Give it its own key

Sets the kernel's keymap entry for the button, so Android sees a real key instead of UNKNOWN.

send

Press any Android key

Presses it on a virtual remote, so it works even when the remote's key layout file doesn't have that key.

run

Run a command

Runs any command with the TV's shell when the button is pressed.

launch

Open an app

Finds the app's TV launcher and starts it.

Careful by design

It changes how your remote is read, so it stays out of the way.

No root
remapd runs as the ADB shell user, which Android already lets change keymaps.
Easy to undo
Whenever remapd stops, it puts the original keymap back.
Checked before it's saved
The app has remapd check a new config first, and keeps the old one as a backup.
Debugging off when idle
Wireless debugging is on only while the app needs it, then off again.
Setup

Set up once, then forget it.

You need a computer with adb for one command. After that, the app does the rest, including starting remapd again after every restart.

  1. 1

    Install the app

    Download the APK from the latest release and install it on the TV. Needs Android 11 or newer, for wireless debugging.

  2. 2

    Allow it from a computer, once

    With the TV connected over adb, run:

    $ adb tcpip 5555
  3. 3

    Open remapd and tap Set up

    The TV asks “Allow USB debugging?”. Choose “Always allow”. The app takes it from there and closes the port when it's done.

  4. 4

    Pick your buttons

    On the Buttons screen, press a button on the remote, choose what it does, and save.
